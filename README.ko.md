# Academic Conference Presentation · v1.0.0

학회 **구두발표(Oral Presentation)** 자료를 제작하는 AI 에이전트용 스킬 패키지입니다.
원자료 검토부터 논지 개요 승인, 선호 색상 기반 디자인 시스템 구축, 편집 가능한 PPTX 및 발표 노트 생성, 렌더링 시각 검수와 과학적 검증까지 전 과정을 단일 작업 흐름으로 지원합니다.

## 패키지 사용 안내

스킬의 진입 파일은 `SKILL.md`입니다. 상세 지침과 보조 스크립트를 상대 경로로 참조하므로, **특정 파일만 분리하지 말고 패키지 폴더 전체를 유지**해야 합니다.
Agent Skills 규격을 지원하는 도구에서는 해당 환경의 안내에 따라 이 폴더를 스킬로 등록하여 사용합니다. (설치 위치와 등록 방식은 사용하는 도구 환경마다 다를 수 있으며, 패키지 파일이 존재한다고 해서 특정 제품에 자동으로 등록되지는 않습니다.)

스킬 자동 탐색을 지원하지 않는 환경이라도 파일 읽기 및 코드 실행 권한이 있다면, 에이전트에게 `SKILL.md`를 먼저 읽고 단계별 지침을 따르도록 요청할 수 있습니다. 단, 파일 접근이나 코드 실행 권한이 없는 단순 텍스트 대화 환경에서는 PPTX 파일이 직접 생성되지 않습니다. 또한, 사용자 동의 없이 외부 변환 서비스나 클라우드로 데이터를 전송하지 않습니다.

## 요청 프롬프트 예시

```text
academic-conference-presentation 스킬로 첨부 논문을 학회 구두발표 자료로 만들어줘.

발표 시간: 12분, 질의응답 별도
청중: 해당 분야 연구자
슬라이드 언어: 영어
발표 노트: 한국어
선호 색: 차분한 보라색 #6D28D9
배경: 밝게
산출물: 편집 가능한 PPTX와 PDF

먼저 슬라이드 제목 흐름, 사용할 근거, 시간 배분과 디자인 방향을 보여줘.
개요 승인 후 전체 자료를 제작해줘.
```

승인 단계를 명시적으로 생략하려면 요청에 다음 문장을 추가하세요.

```text
개요 승인 단계는 생략하고 바로 제작해줘.
다만 확인되지 않은 연구 결과나 수치는 만들어 넣지 마.
```

## 기본 실행 흐름

```text
입력 조건 및 실행 환경 확인
  → 원자료 검토 및 주장별 근거 매핑
  → 슬라이드 제목·근거·시간·디자인 개요 제안
  → 사용자 개요 승인 (또는 명시적 승인 생략)
  → 테마 팔레트·폰트 확정 및 시각 자료 준비
  → PPTX 슬라이드 빌드 및 발표 대본(노트) 내장
  → 구조 점검 + PDF/PNG 렌더링 + 전 슬라이드 시각 검수
  → 원자료 대조 과학적 정밀 검증
  → 최종 산출물 및 QA 보고서 전달
```

사용자 입력이 없을 때 적용되는 기본값은 **발표 시간 15분(질의응답 별도), 16:9 비율, 밝은 배경, 주 색상 파랑(`#2457C5`), 대화 시 사용한 언어(슬라이드 및 발표 노트), 개요 사전 승인 필수**입니다.
이 기본값은 원활한 진행을 위한 작업 가정이므로 학회 공식 규정이 아닙니다. 연구 결과, 표본 크기, 통계 검정 결과 등 과학적 사실에는 기본값을 임의로 적용하거나 조작하지 않습니다.

## 구성

| 경로 | 역할 |
|---|---|
| `SKILL.md` | 호출 조건, 핵심 원칙, 단계별 작업 절차, 승인 및 산출물 규정 |
| `references/scientific-content.md` | 근거 추적, 연구 유형별 구성, 수치 보존 및 인용 주의사항 |
| `references/korean-writing.md` | 한국어 슬라이드 및 발표 노트 작성 지침 (추상화 금지, 전문 문체, 예문 대비표) |
| `references/design-system.md` | 선호 색상 변환, 색상 역할 체계, 한국어 폰트, 레이아웃 규격 |
| `references/production.md` | 도구 선택, figure 추출, 실제 PPTX 제작 및 렌더링 경로 |
| `references/qa.md` | 승인·과학적 정확성·구조·시각·노트 5대 품질 검수 게이트 기준 |
| `references/sources.md` | 검증된 공식 표준 및 라이브러리 API 문서 |
| `assets/` | 입력 조건, 개요, 슬라이드 계획, 근거 기록, QA 보고서 템플릿 |
| `scripts/` | 실행 환경 점검, 색상 생성, figure 추출, PPTX 보조, 렌더링 및 구조 점검 |
| `VALIDATION.md` | 이 패키지에서 실제 검증한 항목과 미검증 범위 |

## 로컬 보조 도구

기본 제작 경로는 `python-pptx → LibreOffice PDF → PyMuPDF PNG`입니다.
사용자가 다른 도구를 명시적으로 요청했거나 특정 실행 환경에서 요구하는 경우 해당 도구를 사용할 수 있으나, 발표 노트 내장, 파일 내보내기, 품질 검수(QA) 기준은 동일하게 충족해야 합니다.

먼저 패키지 디렉터리에서 실행 환경을 점검합니다.

```bash
python scripts/preflight.py
```

필요한 Python 패키지는 `requirements.txt`에 명시되어 있으며, 별도로 설치해야 합니다. 단, LibreOffice 프로그램과 한국어 폰트는 Python 패키지 매니저로 설치되지 않으므로 시스템에 미리 설치되어 있어야 합니다. 폰트 이름을 지정한다고 해서 시스템에 해당 폰트가 자동 설치되거나 PPTX 파일에 자동 임베딩되는 것은 아닙니다.

### 도구 실행 명령 예시 (한 줄 명령)

**Bash (Linux / macOS):**
```bash
# 테마 파일 생성
python scripts/make_theme.py --accent "#6D28D9" --font "Noto Sans CJK KR" --out work/theme.json

# 3장 기능 점검 덱 생성 및 렌더링
python scripts/smoke_test.py --out-dir work/smoke --render
```

**PowerShell (Windows):**
```powershell
# 테마 파일 생성
python scripts/make_theme.py --accent "#6D28D9" --font "Noto Sans CJK KR" --out work/theme.json

# 3장 기능 점검 덱 생성 및 렌더링
python scripts/smoke_test.py --out-dir work/smoke --render
```

`smoke_test.py`는 **실제 연구 데이터가 포함되지 않은 3장짜리 기능 검증용 슬라이드**를 생성합니다. 한글 폰트가 자동 감지되지 않는 환경에서는 시스템에 설치된 폰트를 확인한 후 `--font "폰트 이름"` 형식으로 지정하세요. `--render` 옵션 실행에는 LibreOffice가 필수입니다. 다시 실행할 때는 기존 결과물이 덮어씌워지지 않도록 새로운 출력 폴더 경로를 지정하세요.

실제 발표자료는 에이전트가 원자료와 승인된 개요를 바탕으로 전용 `build_deck.py`를 직접 작성하여 빌드합니다. 패키지에 포함된 `pptx_helpers.py`는 편집 가능한 텍스트 상자 및 도형 배치, 이미지 비율 유지, 동아시아(East Asian) 폰트 지정, 발표 노트 삽입 등을 지원하는 보조 모듈입니다. 모든 연구 유형의 레이아웃을 전자동으로 완성하거나 논문의 과학적 가치를 스스로 판단하는 도구는 아닙니다.

## 색상 엔진의 범위

선호 색상을 슬라이드의 모든 요소에 일괄 적용하는 대신 주 강조색, 강조 글자색, 틴트 배경색, 기본 본문색, 비교 대상색 등으로 역할을 명확히 나누어 배정합니다. 명도 대비가 부족하면 해당 역할의 명도를 자동 조정하며, 원래 요청받은 선호 색상값은 메타데이터에 기록합니다. 학술적 의미가 담긴 히트맵(Heatmap), 현미경 사진, 컬러 스케일 등 원본 시각 자료의 색상은 테마에 맞춰 임의로 변경하지 않습니다.

도구를 통한 대비 수치 검사 통과가 프로젝터 현장 가독성이나 색각 이상 접근성을 완벽히 보장하지는 못하므로, 실제 슬라이드 렌더링 이미지를 직접 육안으로 점검해야 합니다.

## 산출물과 검수 상태

발표자료 제작 완료 시 기본 산출물은 `presentation.pptx`, `speaker-notes.md`, `outline.md`, `qa-report.md`이며, 정상적으로 PDF 변환이 완료되면 `presentation.pdf`도 함께 제공합니다. 빌드 스크립트, 테마 설정, 근거 매핑 데이터, 사용한 이미지 에셋은 결과 재현을 위해 프로젝트 디렉터리에 보존합니다. 비공개 원자료나 재배포 권한이 없는 연구 자료는 동의 없이 패키지에 포함하여 배포하지 않습니다.

품질 검수 항목은 `PASS`, `FAIL`, `NOT_RUN`으로 명확히 기록합니다. 원자료 대조 검증이나 렌더링 시각 검사를 생략한 경우 임의로 검수 완료로 표시하지 않습니다. 자동화 구조 검사를 통과했더라도 텍스트 넘침 없음, 과학적 정확성, 실제 발표장 환경과의 호환성을 보장하는 것은 아닙니다.

스킬 자체의 작업 절차와 규칙은 표준화되어 있으나, 제작되는 **각 발표자료의 학술적 정확성과 레이아웃은 매 실행마다 독립적으로 검증**해야 합니다.
