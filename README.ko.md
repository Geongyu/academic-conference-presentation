# Academic Conference Presentation · v1.0.0

학회 **구두발표** 자료를 제작하는 AI 에이전트용 스킬 패키지입니다.
원자료 검토, 논지 개요 승인, 선호 색상 기반 디자인, 편집 가능한 PPTX,
발표 노트, 렌더링 검수와 과학적 검증을 하나의 작업 흐름으로 연결합니다.

## 무엇을 사용하면 되나요?

진입 파일은 `SKILL.md`입니다. 상세 지침과 보조 스크립트를 상대 경로로
참조하므로 **파일 하나만 떼지 말고 폴더 전체를 함께 보관**하세요.
Agent Skills를 지원하는 환경에서는 해당 환경의 설치 방식으로 이 폴더를
등록합니다. 설치 위치·등록 방식은 사용하는 제품에 따라 다릅니다.
이 패키지를 제공한 것만으로 어느 제품에 자동 설치된 것은 아닙니다.

스킬 자동 탐색을 지원하지 않는 환경에서도 파일 읽기와 실행 기능이 있다면
`SKILL.md`를 먼저 읽고 단계별로 필요한 파일을 참조하도록 지시할 수 있습니다.
파일이나 코드 실행 기능이 없는 대화 환경에서는 지침만으로 PPTX가 생성되지
않습니다. 외부 변환 서비스나 클라우드 업로드는 자동 실행하지 않습니다.

## 요청 예시

```text
academic-conference-presentation 스킬로 첨부 논문을 학회 구두발표 자료로 만들어줘.

발표 시간: 12분, 질의응답 별도
청중: 해당 분야 연구자
슬라이드 언어: 영어
발표 노트: 한국어
선호 색: 차분한 보라색 #6D28D9
배경: 밝게
산출물: 편집 가능한 PPTX와 PDF

먼저 슬라이드 제목 흐름, 사용할 근거, 시간 배분과 디자인 방향을 보여줘.
개요 승인 후 전체 자료를 제작해줘.
```

승인 단계를 명시적으로 생략하려면 요청에 다음 문장을 추가하세요.

```text
개요 승인 단계는 생략하고 바로 제작해줘.
다만 확인되지 않은 연구 결과나 수치는 만들어 넣지 마.
```

## 기본 실행 흐름

```text
입력·실행 환경 확인
  → 원자료 검토 + 주장별 근거 기록
  → 슬라이드 제목·근거·시간·디자인 개요
  → 사용자 승인 또는 명시적 승인 생략
  → 팔레트·폰트 확정 + figure 준비
  → PPTX 제작 + 발표 노트 내장
  → 구조 점검 + PDF/PNG 렌더링 + 전 슬라이드 시각 검수
  → 원자료 대조 검증
  → 최종 산출물과 QA 보고서 전달
```

입력이 없을 때의 기본값은 **15분 발표, Q&A 별도, 16:9, 밝은 배경,
파랑 `#2457C5`, 대화 언어의 슬라이드와 노트, 개요 승인 필요**입니다.
이 값들은 작업 가정이며 학회의 공통 규정이 아닙니다. 연구 결과·표본수·통계
검정 등 과학적 내용에는 기본값을 적용하지 않습니다.

| 경로 | 역할 |

| `SKILL.md` | 호출 조건, 핵심 원칙, 단계별 작업, 승인·산출물 규칙 |
| `references/scientific-content.md` | 근거 추적, 연구 유형별 구성, 수치·인용 주의점 |

| `references/production.md` | 도구 선택, figure 추출, 실제 PPTX 제작·렌더링 경로 |
| `references/qa.md` | 승인·과학적 정확성·구조·시각·노트의 검수 기준 |
| `references/sources.md` | 확인한 공식 형식/API 문서 |
| `assets/` | 입력 조건, 개요, 슬라이드 계획, 근거 기록, QA 보고서 양식 |
| `scripts/` | 실행 환경 확인, 색상 생성, figure 추출, PPTX 보조, 렌더링·점검 |
| `VALIDATION.md` | 이 패키지에서 실제 확인한 범위와 미검증 범위 |

## 로컬 보조 도구

기본 제작 경로는 `python-pptx → LibreOffice PDF → PyMuPDF PNG`입니다.
다른 제작 도구가 명시적으로 요청되거나 실행 환경에서 지정되어 있으면 그
도구를 사용할 수 있지만, 노트·내보내기·검수의 요구사항은 유지합니다.

먼저 패키지 폴더에서 실행 환경을 확인하세요.

```bash
python scripts/preflight.py
```

필요한 Python 패키지는 `requirements.txt`에 있습니다. 의존성 설치는 별도로
진행해야 합니다. LibreOffice와 한국어 폰트는 Python 패키지 설치에 포함되지
않습니다. 폰트 이름을 지정하는 것만으로 설치·임베딩되지는 않습니다.

```bash
python scripts/make_theme.py --accent '#6D28D9' \
  --font 'Noto Sans CJK KR' --out work/theme.json

python scripts/smoke_test.py --out-dir work/smoke --render
```

`smoke_test.py`는 **실제 연구 결과가 없는 3장짜리 기능 점검 덱**을 만듭니다.
한글 폰트가 자동 확인되지 않는 환경에서는 설치된 폰트를 확인한 다음
`--font '폰트 이름'`을 지정하세요. `--render`에는 LibreOffice가 필요합니다.
재실행할 때는 새 출력 폴더를 사용하세요.

일반 발표자료는 AI가 원자료와 승인된 개요에 맞춰 `build_deck.py`를 작성합니다.
`pptx_helpers.py`는 편집 가능한 텍스트·도형, 이미지 비율 보존, East Asian
폰트 설정, 발표 노트 저장을 제공하는 기본 도구입니다. 모든 연구의 레이아웃을
자동으로 완성하거나 논문의 과학적 의미를 판정하는 프로그램은 아닙니다.

## 색상 엔진의 범위

선호색을 그대로 모든 요소에 바르는 대신 기본 강조색, 강조 글자색, 연한 면,
일반 글자색, 비교 대상색을 구분합니다. 대비가 낮으면 해당 역할의 명도를
조정하고 원래 선호색을 별도로 기록합니다. 과학적 의미가 있는 heatmap,
현미경 이미지, 컬러 스케일은 테마에 맞춰 임의 변경하지 않습니다.

대비 수치 통과는 프로젝터 가독성이나 색각 접근성의 완전한 보장이 아닙니다.
실제 슬라이드를 렌더링해 확인해야 합니다.

## 산출물과 검수 상태

발표 제작 시 기본 산출물은 `presentation.pptx`, `speaker-notes.md`,
`outline.md`, `qa-report.md`이며, 내보내기가 성공하면 `presentation.pdf`도
전달합니다. 제작 코드·테마·근거 기록·사용 자산은 재현용 프로젝트에 남깁니다.
비공개 원자료와 재배포 권한이 없는 자료는 무조건 묶어 배포하지 않습니다.

검수 항목은 `PASS / FAIL / NOT_RUN`으로 구분합니다. 원자료 검증이나 렌더링
검사가 수행되지 않았다면 검수 완료로 표시하지 않습니다. 구조 검사 통과는
텍스트 넘침, 과학적 정확성 또는 실제 발표장 호환성 검증을 뜻하지 않습니다.

이 스킬의 작업 절차는 최종본으로 정리되어 있지만, 제작되는 **각 발표자료의
정확성과 레이아웃은 실행할 때마다 검증**해야 합니다.
