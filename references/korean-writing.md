# 학술 발표 국문 작성 지침 (Korean Writing Guidelines)

본 문서는 한국어로 학술 구두발표 슬라이드와 발표 노트를 작성할 때 에이전트가 준수해야 하는 실무 지침서이다. 슬라이드 언어나 발표 노트 언어가 한국어로 지정되었을 때 필수 적용한다. 과학적 정확성(수치 보존, 과장 금지)을 최우선으로 하며, 가독성을 높이되 학술적 개념과 조건이 왜곡되거나 축소·확대되어서는 안 된다.

## 1. 4대 필수 규칙 (Non-negotiable)

1. **추상화 금지 (구체적 지표 및 수치 명시)**
   - "효율성 대폭 향상", "다양한 요인 분석", "유의미한 결과 달성", "성능 최적화" 등 뭉뚱그린 모호한 표현을 전면 금지한다.
   - 항상 **무엇이**, **얼마나(정량적 수치 및 비교 기준)**, **어떻게(방법·조건)** 개선되고 변화했는지 구체적으로 기술한다.
   - 수치가 존재하는 연구 결과는 반드시 원문의 측정 단위와 변화량을 함께 명시한다.
2. **모델 사고과정 노출 금지 (오직 발표 내용만 기술)**
   - 슬라이드 본문과 발표 노트 어디에도 모델의 내부 추론, 작업 메모, 자기 점검 문장을 남기지 않는다.
   - 금지 표현: "~로 판단됨", "검토 결과", "가정:", "이 슬라이드에서는 ~를 강조해야 함", "[메모: 시간 조절 필요]".
   - 에이전트의 메타 발언을 완전히 배제하고, 오직 연구자가 학회 청중에게 직접 전달하는 학술적 발표 내용만 작성한다.
3. **학회 청중 수준의 전문 문체 유지**
   - 처음 듣는 동료 연구자도 논리 전개를 쉽게 파악할 수 있도록 간결하고 명확하게 서술한다.
   - 이해를 돕는다는 명목으로 초등학생에게 설명하듯 전문 학술 개념을 유아적 비유나 장황한 일상어로 과도하게 풀어서 쓰지 않는다.
   - 학계에서 통용되는 전문 용어의 엄밀성을 유지하며 격조 있는 학술 발표 문체를 견지한다.
4. **자기만 아는 단어 금지 (내부 식별자 및 미정의 약어 금지)**
   - 시스템 파이프라인 변수명, 내부 라벨, 파일 경로(`claim_id`, `evidence locator`, `slide-plan`, `Fig 3a_crop` 등)를 절대 노출하지 않는다.
   - 연구자가 자체 정의한 임시 약어나 비표준 약어를 슬라이드·노트에 단독으로 쓰지 않는다.
   - 학계 표준 약어라도 슬라이드와 노트에서 첫 등장 시 반드시 정식 명칭을 풀어 쓴다.

## 2. 학회 발표 국문 실무 규칙

- **슬라이드 제목**: 단순 주제 명사 나열("실험 결과", "성능 평가")이나 막연한 의문형을 피하고, 슬라이드가 입증하는 핵심 발견을 담은 **주장형 문장(Claim title)**으로 작성한다. 1줄(공백 포함 35자 내외, 최대 2줄 이내)로 한눈에 읽히도록 구성한다.
- **슬라이드 본문**: 불릿 포인트 기반의 개조식으로 구성하며, 슬라이드당 3~5개 불릿 이내로 제한한다. 문장 종결은 명사형(예: ~구축, ~검증, ~감소) 또는 일관된 체언 종결로 통일하여 시각적 직관성을 극대화한다. 불릿 간 종결 어미 혼용(~함, ~임, ~했음)을 금지한다.
- **발표 노트**: 청중에게 구두로 설명하듯 정중하고 자연스러운 구어체 존댓말(~합니다, ~습니다)로 작성한다. 슬라이드 텍스트를 단순 낭독하지 않고 시각 자료의 해석, 데이터 간 연결 고리, 다음 슬라이드로의 전환 맥락을 제공한다. 발화 분량은 한국어 기준 **분당 300~350자**(공백 포함)를 근사 기준으로 삼아 슬라이드별 예상 시간과 맞춘다. 발표자 실제 속도가 알려지면 그 값을 우선한다.
- **숫자·단위·통계 표기**:
  - **단위 띄어쓰기**: 숫자와 단위 기호 사이는 한 칸 띄운다(예: `10 kg`, `5 mL`, `24 nm`, `100 s`). 단, 백분율(`%`), 섭씨온도(`℃`), 각도(`°`) 기호는 숫자에 붙여 쓴다(예: `95%`, `36.5℃`, `45°`).
  - **통계 기호**: 영문 통계 기호는 이탤릭체(*p*, *t*, *F*, *N*, *R*²)로 표기하며, 유의확률은 부등호 및 공백을 정돈한다(예: *p* < .05, *p* = .023). 표본 크기는 대문자 이탤릭(*N* = 120)으로 적는다.
  - **신뢰구간 및 범위**: 신뢰구간은 대괄호로 병기하며(예: 95% CI [1.2, 3.4]), 수치 범위는 물결표(`~`) 또는 엔 대시(`–`)를 일관되게 사용한다(예: `10~20 mg`).
  - **% vs %p 구분**: 백분율 자체와 백분율 간의 산술적 차이인 백분율 포인트를 엄격히 구분한다(예: 70%에서 75% 증가는 +5%p, 7.1% 증가). 원문의 수치와 유효숫자는 왜곡 없이 보존하며 임의 반올림을 금지한다.
- **영문 전문용어 병기**: 학계 통용 표준 국문 번역어가 있는 경우 국문을 우선 표기하고 영문 원어를 괄호 병기한다(예: 합성곱 신경망(CNN), 지도학습(Supervised Learning)). 직역 시 의미가 왜곡되거나 학계에서 영문 단독으로 주로 쓰이는 고유명사·기술용어(예: Transformer, ResNet, Dropout, Ablation)는 원어 그대로 사용한다. 쉬운 우리말로 무리하게 치환하다가 학술적 정의가 훼손되어서는 안 된다.
- **번역투 및 피동 남용 지양**: 일본어·영어 직역투 표현(~에 대하여, ~의 경우, ~을/를 통해, ~에 의해, ~를 필요로 하다)과 이중피동(~되어지다, ~불려지다, ~보여진다)을 지양하고, 명확하고 능동적인 서술어(~를 분석, ~가 드러남)를 사용한다.
- **시각 자료 레이블 및 줄바꿈**: 차트 축 레이블은 `변수명 (단위)` 형식을 준수한다(예: 지연 시간 (ms)). 한국어 텍스트 상자는 어절 단위로 자연스럽게 행바꿈이 일어나도록 너비를 확보하고, 낱말 중간에 어색한 줄바꿈이 생기지 않도록 여백을 조절한다.

## 4. 제출 전 셀프 점검 체크리스트

### [필수 원칙 점검]
- [ ] **구체성 검증**: "유의미한", "효율적", "다양한" 등 모호한 추상어가 구체적 지표와 정량 수치로 대체되었는가?
- [ ] **사고과정 배제**: 슬라이드와 발표 노트에 에이전트의 작업 메모, 가정, 판단 과정 문장이 완전히 배제되었는가?
- [ ] **학술 어조 유지**: 청중(연구자) 수준에 적합한 전문성을 갖추었으며, 지나치게 유아적으로 풀지 않았는가?
- [ ] **식별자 정제**: `claim_id`, `slide-plan` 등 내부 변수명이 없으며, 생소한 약어는 첫 등장 시 정의되었는가?

### [실무 형식 점검]
- [ ] **제목 주장형**: 슬라이드 제목은 단순 명사 나열이 아닌 핵심 발견을 담은 주장형 문장(1~2줄 이내)인가?
- [ ] **본문 종결 통일**: 본문 불릿 포인트의 종결 어미가 명사형으로 일관되게 정돈되었는가?
- [ ] **발표 노트 완성도**: 발표 노트는 청중에게 직접 말하는 구어체(~합니다)이며, 발화 분량(분당 300~350자)이 계획된 시간과 부합하는가?
- [ ] **수치 및 단위 정확성**: 숫자-단위 띄어쓰기, %, %p 구분, 통계 표기(*p*, CI)가 올바르며 원자료와 일치하는가?
- [ ] **문장 정제**: 번역투(~에 의해, ~에 대하여)나 이중피동(~되어지다) 없이 간결하고 명확한 능동형 문장인가?
- [ ] **시각 레이아웃 적합성**: 텍스트 상자 내 단어 중간 강제 줄바꿈이 없으며, 차트 축 레이블 형식이 정돈되었는가?
- [ ] **과학적 무결성**: 쉬운 말로 풀다가 본래의 과학적 의미, 인과관계, 제약 조건이 왜곡되거나 축소·과장되지 않았는가?
